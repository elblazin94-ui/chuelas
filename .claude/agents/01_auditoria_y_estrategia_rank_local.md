# Rank Local - Fase 01: Auditoría y Estrategia
Instalación: `$ npx skills add https://github.com/calm-north/seojuice-skills --skill rank-local`

## Marco de Trabajo de 6 Pasos
1. **Auditoría de Perfil (GBP):** Nombre (sin keyword stuffing), categorías, dirección, teléfono, web, horarios y descripción.
2. **Contenido Visual:** Logo, portada, +10 fotos y videos.
3. **Funciones Activas:** Google Posts (semanales), Productos/Servicios, Q&A, Mensajería y enlaces de reserva.
4. **Consistencia NAP:** Nombre, Dirección y Teléfono idénticos en web, GBP y directorios.
5. **Estrategia de Reseñas:** Responder a todo en menos de 24h.
6. **Schema Local:** Implementar JSON-LD para `LocalBusiness`.
